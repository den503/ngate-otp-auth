# Клиент NGate VPN с OTP-аутентификацией

Данное приложение представляет собой консольный клиент для подключения к VPN-серверу NGate с использованием многофакторной аутентификации, включая одноразовые пароли (OTP).

## Возможности

- 🔐 Безопасное подключение к VPN-серверу NGate
- 🔑 Автоматическая генерация OTP-токенов
- 💾 Надежное хранение зашифрованных учетных данных
- 🔄 Поддержка смены пароля
- 🔒 Шифрование всех конфиденциальных данных с использованием мастер-пароля

## Требования

- Python 3.12+
- Установленный клиент NGate Console Client (`/opt/cprongate/ngateconsoleclient`)
- Доступ к VPN-серверу (`https://ngvpn.1cupis.org`)

## Установка

1. Клонируйте репозиторий:
```shell script
git clone <url-репозитория>
   cd ngate-otp-auth
```


2. Создайте и активируйте виртуальное окружение (опционально):
```shell script
python -m venv venv
   source venv/bin/activate  # для Linux/Mac
   # или
   venv\Scripts\activate  # для Windows
```


3. Установите зависимости:
```shell script
pip install -r requirements.txt
```


## Зависимости

- **cryptography**: Для шифрования и защиты учетных данных
- **pexpect**: Для взаимодействия с внешним VPN-клиентом
- **pyotp**: Для генерации одноразовых паролей

## Использование

1. Запустите программу:
```shell script
python main.py
```


2. При первом запуске вам будет предложено ввести:
   - Логин для VPN-соединения
   - Пароль
   - Секретный ключ для генерации OTP
   - Мастер-пароль для шифрования данных

3. Дальнейшие действия доступны через меню:
   - Подключение к VPN
   - Смена пароля
   - Выход из программы

## Безопасность

- Все конфиденциальные данные шифруются локально
- Мастер-пароль не сохраняется и требуется для расшифровки при каждом использовании
- Используется стойкое шифрование через библиотеку cryptography
- Пароль и секретный ключ никогда не хранятся в открытом виде

## Структура проекта

- **main.py**: Основной файл программы с логикой меню
- **database.py**: Управление хранением зашифрованных учетных данных
- **connection.py**: Логика подключения к VPN и взаимодействия с клиентом
- **crypto.py**: Функции шифрования и расшифрования данных
- **utils.py**: Вспомогательные функции ввода и обработки данных
- **credentials.json**: Файл с зашифрованными учетными данными (создаётся автоматически)

## Примечания

- Приложение предназначено для работы с VPN-клиентом NGate
- При подключении к VPN можно прервать соединение нажатием Ctrl+C
- Для корректной работы необходимо наличие установленного клиента NGate по пути `/opt/cprongate/ngateconsoleclient`
